# ✈️ TravelBuddy – Flight Search Automation Bot

🚀 An intelligent automation bot that collects user travel inputs, searches for flights, extracts data, and delivers results via email with Excel attachment.

---

## 🔥 Overview

**TravelBuddy** is an automation-based project that simulates a real-world travel assistant. It takes user inputs (source, destination, date, email), fetches flight data, stores it in an Excel file, and sends it to the user via email.

---

## 🧠 Project Highlights

- 🤖 Automated flight search workflow  
- 📥 User input handling (Source, Destination, Date, Email)  
- 📊 Data extraction & Excel generation  
- 📧 Email automation with attachment  
- 📝 Logging system for tracking  
- ⚠️ Exception handling for reliability  

---

## 🏗️ Workflow

User Input → Flight Search → Data Extraction → Excel File → Email Sent to User

---

## ✨ Features

- ✈️ Search flights based on user input  
- 📄 Extract relevant flight details  
- 📊 Generate structured Excel report  
- 📧 Send email with attachment  
- 📝 Maintain logs for execution tracking  
- ⚠️ Robust error & exception handling  

---

## ⚙️ Tech Stack

Language: Python  
Automation: Selenium / Web Automation  
Data Handling: Pandas  
Excel: OpenPyXL / Pandas  
Email: SMTP  
Logging: Python Logging Module
